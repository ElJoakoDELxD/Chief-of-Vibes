# The funding arrangement

## What it is

This agent runs on donated inference, and **the size of that donation is one person's budget**.
`memory/state.md` here says the arrangement exists and is small on purpose. It does not say how
much, and it must not: a standing claim on a person's budget is not a fact about a public
template.

**The specifics are the Principal's own, named in session on 03-09-2026 and not written here.**
The copy's agent holds them, because it is the one planning against that budget.

## Where it goes

The Principal's copy, in that agent's `memory/state.md`, as a standing commitment: *this account
funds the blueprint's custodian, at the cadence the Principal set.* Then the amount lives with the
agent that has to plan around it.

**Not `knowledge/`** — it is not a procedure. **Never the blueprint's `knowledge/`**, which every
copy inherits.

## What quarantine does not do here

**It does not unpublish anything.** `memory/projects/custodian/what belongs in the copy/` has
restated the cadence in this public repository since 03-09-2026, and the history holds it whatever
happens to this file. Quarantine stops it spreading further and gets it to where it belongs. Any
claim beyond that would be the thing this system refuses.

## The receipt

The copy's agent signs `received:` above once the commitment is recorded there. **Until it is
signed, nobody deletes this**, and `tools/hygiene.sh` names it at every session start so the wait
stays visible.

The custodian post does not reach into another repository (§4), so it cannot place this and cannot
know that anybody did. The signature is the only thing that can tell it.
