## The measurement that decides it

A green bench proves nothing on its own when the bench ships in the same commit as the fix.
The question is whether the new cases fail without it.

**They do.** The proposed `tools/test-guard-main.sh` was run against the current
`.claude/hooks/guard-main.sh` from `main`:

```
FAIL  want=PASS  got=BLOCK  [on main] git checkout -b agent-branch
FAIL  want=PASS  got=BLOCK  [on main] git switch -c agent-branch
FAIL  want=PASS  got=BLOCK  [on main] git checkout -b feature/some-work
3 failing
```

Exit code 3 with those failures, 0 with the fix in place, so CI catches a regression rather
than reporting one in prose. The bench goes from 23 cases to 38, and the 15 new ones are the
half that had no coverage: the fixture repository stands on the default branch, which the old
bench never did because it ran from whatever branch the session was already on.

The claim in the commit message holds as written.

## The hook diff, read adversarially

The escape is one shape: a lone branch-creating checkout, no chaining, no redirection, no
substitution, and a name that is not the default branch. Thirteen probes beyond the bench:

- A newline followed by a second command — **blocked**, twice. The trailing `[[:space:]]*$`
  anchor catches what the metacharacter class does not.
- The default branch name quoted, single or double — **blocked**. Quotes are stripped before
  the name is compared.
- `--` followed by `; id`, and `--` followed by a substitution — **blocked**.
- A leading environment assignment — **blocked**. The regex anchors on `^[[:space:]]*git`.
- Edit and Write carry no command field, so they can never reach the escape — **blocked**,
  and the bench covers this.

**The one miss: `git checkout -b x)` passes.** The metacharacter class holds `(` and not `)`.
It is inert: an unbalanced `)` is a bash syntax error, nothing runs, and `(` is blocked so no
subshell can be opened for it to close. Worth a character the next time that line is touched,
not worth a round trip now.

rail reads text, not intent. The entry was three weeks old and this agent had read its header
and not its procedure.

first time. **`knowledge/` paid for itself on the first run of the guard**, which is the
argument for the folder that no amount of describing it makes.
