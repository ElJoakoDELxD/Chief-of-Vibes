- Recorded the copy as `animated-octo-enigma` and the decision to hold the `knowledge/` fix

### Decided

- **The report does not go on the pull request.** `state.md` already says why: a recommendation
  does not have to be posted where the decision lives, which is also why this agent needs no
  write access to anybody's pull requests. It goes to the Principal and into memory.
- **The one miss is not a round trip.** `git checkout -b x)` passes the escape because the
  metacharacter class holds `(` and not `)`. An unbalanced `)` is a bash syntax error and `(`
  is blocked, so nothing can run. Reporting it as a blocker would buy a cycle and no safety.

### Lessons

- **`knowledge/` paid for itself on the guard's first run, and it did so by catching this
  agent.** The probe script was refused because it contained the words `git init -b <default>`.
  That is `the-guard-reads-text-not-intent.md`, three weeks old, describing this exact refusal.
  Its header had been read this afternoon and its procedure had not. The fix was the entry's
  own — move the text into a file, hand the rail a path — and it worked first time.

  The failure is not that the entry was missing. It is that reading a folder's headers feels
  like having read the folder. CLAUDE.md says to check `knowledge/` before working out a
  procedure from scratch, and the check that was run was a listing.

- **A bench shipped with its own fix proves nothing until it is run against the code without
  the fix.** Every bar #75 clears, it clears because the same commit supplies both sides. The
  differential is the only measurement in the report that could have come out otherwise, and
  it is the one the door should always ask for. Candidate for the guard's step 2 as a written
  step rather than as today's good judgment. `#propagate:03-09-2026`
