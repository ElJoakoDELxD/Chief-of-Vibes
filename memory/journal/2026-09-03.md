## Lessons

- **The 04:18 session is the finding, not the pull request it opened.** It did good work — a
  live guard defect, fixed, with fifteen new bench cases — and wrote none of it down. Nine
  hours later that work had to be reconstructed from a commit message. Every rule about pushing

  answer is to climb, not to promise harder.

  `tools/models.sh`, and `tools/challenge.sh` in the weekly-guard note. All three were written
  in the present tense on 14 and 15-08-2026. A paragraph that describes a control in the
  present tense is read as a control. The Custodian's own identity file was the first place in
  this repository to do the thing the Custodian exists to catch.

- **The canon's own agent is the case the canon documents least.** §9 says no agent is created
  on the canon, and it is right for every visitor. It has no sentence for the maintainer's own
  agent, which already existed on this repository before today. Candidate for propagation, and
  it is not obviously worth a rule — one exception described in prose may be cheaper than a
  clause. `#propagate:03-09-2026`
