## Decided

- **Custodian is a role, not an agent.** Set by the Principal. Chief of Vibes is the agent and the
  only one with access to the role. Both `state.md` files put the role name in the `agent` field,
  which is how one agent ended up with two vaults.
- **The canon is everyone's workspace.** It exists to receive what copies prove. Nobody edits it
  directly because a direct edit reaches no review, no version and no copy, not because anybody is
  unwelcome. Everyone comes through the same door, the agent standing on the canon included.
- **Custody is the role's and never ships.** `.canon` conflates three facts: custody, parent, and
  root. The template carries no custody marker.
- **The charter does not ship before its mechanism.** A document describing a control that is not
  built is the defect already recorded twice here.

## Lessons

- **A branch is not a repository.** This session read a superseded `state.md` for its whole length
  because nothing checked `git ls-remote --heads` for a second vault. It then reported two
  documented backlog items as discoveries and wrote a plan against a tree two releases stale.
- **A test that pins a wall-clock offset has an expiry date.** It reads as correct for months.
- **The second hop has no sensor.** Hop one is checked at session start and skipped on the canon by
  construction, so nothing watches the branch where the work happens.
- **Three verdicts in one thread, each right about the mechanism and wrong about the frame.** The
  frame came from the Principal every time. Measuring a proposal against the specification as
  written cannot find an error in the specification's own model.
