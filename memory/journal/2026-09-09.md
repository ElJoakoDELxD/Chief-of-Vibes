## Lessons

- **A release is not tested by the mechanism it changes.** 1.81.0 shipped green and broke three
  things, each found by running the system: the clock, the two-vault sensor, and the vault itself.
- **The install path is a mechanism too.** Every rule about what sync does was written as though the
  sync applying it already had it. That is true from the second sync onward and never for the first.
- **The restore is the report.** Fixing it quietly would have left the next agent believing a merge
  cannot eat a vault.
- **A fourth tool read presence instead of a value.** `sweep-branches.sh` protected two dead release
  branches, because the empty form they inherited looked like an identity. Its bench passed the whole
  time: **the bench built a filled form and the shipped one is empty.** Folded into #95.

## Decided

- **The blast radius of a shipped input is every tool that reads it.** Four asked whether an agent
  lives here; three were fixed with the release and the fourth was missed. §5 now lists all four, so
  the next tool that asks has somewhere to look.
