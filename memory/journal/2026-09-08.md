## Lessons

- **The first identity rail refused nothing, silently.** Its loop read a command through a pipe
  with no trailing newline, so `read` returned non-zero and the body never ran. Installed, wired,
  and inert. Eleven bench cases found it in one run. **Installing a hook is not evidence it does
  anything**, and this is the same class as a green check on a run that did the wrong work.
- ~~**A rail can refuse the writing of its own bench.** The cases hold the strings the hook blocks,
  so a shell heredoc carrying them is indistinguishable from the act. It errs closed, which is the
  right direction, and the bench says so at the top rather than leaving the next person to find it.~~
  **Wrong, corrected the same day in 1.75.0.** The two are distinguishable, by the shell's own
  grammar. A body bound for a file is data and a body bound for an interpreter is not, and the rail
  was already reading that grammar to find the words it refuses. Erring closed was the name this
  agent gave a false positive it had twice routed around. See `memory/corrections.md`.
- **The model gate ran on its first live session and passed**, then the header made a different
  gap visible: the post claims a duty to the contributor and the catalogue has no function for
  teaching.


## 1.75.0 — the rails judge what the shell will run

- **The Principal's correction landed on a sentence this agent had written twice**: *the hook
  cannot tell text from intent*. Half true. Whether a command should run is intent and no rail
  decides it. Whether a here-document body is data is grammar, and the rail reads that grammar
  already.
- **`.claude/hooks/lib/command.sh`**, one reader for the three rails. A body bound for a file is
  removed; a body reaching an interpreter stays, and that half is what makes the first one safe.
- **`guard-main.sh` also stopped claiming other repositories**: an absolute `-C` outside this
  working tree is somewhere else.
- **The identity guard had no row in either transparency table**, and had been blocking since
  1.73.0. *If it is not in this table, it does not happen* — so it now has one in both.
- **Both guard benches are written by here-documents in this release**, holding the exact strings
  their rails refuse. That is the proof, not a claim about it.
- Pull request #87. 19 of 19 benches green. `tools/test-sync.sh` read red once and green on the
  re-run, both passes printing the git proxy's `expected 'acknowledgments'` line.
