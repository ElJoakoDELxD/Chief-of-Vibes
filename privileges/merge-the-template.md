# Merge the template

The template branch is read-only in operation (§6). This is the grant that lets one post move
it, and it moves it only through a pull request somebody approved.

## What is mechanical

The remote refuses a push to a protected branch and refuses a merge whose required checks have
not passed. Neither depends on the agent remembering anything, and neither can be talked out of.

## What is not, and it is the larger half

**Nothing at the remote distinguishes a merge the Principal approved from one the agent decided
on.** The approval is the control, it is judgment, and §8's ladder says judgment cannot climb.
An agent that merges without it has not defeated a rail; it has broken a rule, and the record of
that is the pull request nobody approved.

So the grant is written here rather than assumed, and a session exercising it says so.
