# Languages

Every language this system has explained itself in, one line each, added the first
time an agent rendered its own capability roster in a language not already listed.

Nobody is asked to add a line. It arrives because somebody used the thing — which
is the only kind of signal this system counts (`SYSTEM.md` §7).

|---|---|
| English | 2026-07-13 |
| Spanish | 2026-08-02 |

## What a line means, exactly

**An agent explained itself in this language, once.** That is the whole claim.

It does not mean an active user, a maintained copy, a finished project, or an
endorsement. Those would all require somebody to still be here, and this file
cannot see that. A count of languages read as a count of adopters is a vanity
number wearing evidence's clothes, and the difference matters most to whoever is
deciding whether to trust this page.

## What a line never carries

Who, where, which repository, which date beyond the day. A language is not a
person and this record stays that way (§7).

**One honest risk, stated before anyone adds their line rather than after:** for a
language with very few speakers, the entry itself narrows who you might be. The
first line in a language is the one that carries this cost, and it is the
Principal's call whether the signal is worth it. Adding a language is never
required — the system works identically whether or not this file ever names
yours.

## Adding one

The agent proposes it the first time it renders the roster in a language absent
here: one line, by pull request into the canon, reviewed like any other change
(§6). It happens once per language ever, so the file grows by use rather than by
effort, and stops growing on its own when the reach stops widening — which is
itself worth knowing.
