# Propose upstream

Take what this repository proved to the blueprint it came from.

## What it does

1. Read `.blueprint` on this branch. Every generation proposes there, and none proxies through
   the copy it came from (§6).
2. Measure the change against the gate, which binds on three at once: **agnostic**, describing
   nobody in particular; **an improvement**, so somebody else is better off holding it; and
   **verified**, run here against real work.
3. Open the pull request in the template's language, whatever language the failure was found in.
4. A change that stays gets a verdict too, naming which of the three it failed.

## What it never carries

No name, no address, no location, no timezone, no private repository name, and no quotation of
anything a person said (§7). The concept travels. The sentence does not.
